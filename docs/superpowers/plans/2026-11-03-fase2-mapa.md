# Fase 2 — Mapa / Link Google Maps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, poucas tarefas interdependentes).

**Goal:** Cliente vê mapa em `/pedido/[code]` quando `saiu`; entregador inicia rota; link Google Maps externo funciona.

**Architecture:** Leaflet + OpenStreetMap embutido, `order_locations` (SQLite) para posição, endpoint POST para atualizar, link `maps/dir/?api=1` sem chave.

**Tech Stack:** Next.js 16, Leaflet (já em `dependencies`), SQLite (`node:sqlite`), React 19.

**Spec:** `docs/superpowers/specs/2026-11-03-fase2-mapa-design.md`

## Global Constraints
- SQLite `DB_DRIVER=sqlite`, tabela `order_locations` já existe, não quebrar `.env.local`.
- Sem chave de API Google para primeira entrega; usar link externo.
- Leaflet já instalado (`leaflet`, `react-leaflet`).

## Review Focus
- GPS negado não quebra entrega.
- Atualização só quando `saiu`; limpa ao `chegou`/`concluido`.
- Link externo funciona em mobile.
