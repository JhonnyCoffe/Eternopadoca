# Curiosidade

## Skills recomendadas para criar prompts

Use `brainstorming` para criar prompts fortes. Ele esclarece objetivo, contexto, restrições, público e resultado esperado antes de escrever.

Combine conforme a tarefa:

- `brainstorming`: descobrir requisitos e montar prompt.
- `opencode`: prompts sobre OpenCode, agentes, skills, MCP ou configuração.
- `writing-plans`: transformar prompt em plano executável.
- `test-driven-development`: prompt para implementar código com testes.
- `systematic-debugging`: prompt para investigar bugs.
- `claude-automation-recommender`: prompt para automações no Claude Code.

## Fluxo recomendado

1. Use `brainstorming`.
2. Escolha domínio específico.
3. Inclua objetivo, contexto, entradas, restrições, formato e critérios de sucesso.
4. Use `writing-plans` se o prompt gerar implementação.

## Estrutura de prompt

```text
Objetivo:
[Descreva resultado desejado]

Contexto:
[Forneça informações necessárias]

Tarefa:
[Explique ação esperada]

Restrições:
[Liste limites, padrões e regras]

Formato da resposta:
[Defina estrutura, idioma e nível de detalhe]

Critérios de sucesso:
[Explique como avaliar resultado]
```
